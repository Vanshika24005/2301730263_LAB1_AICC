# AI-Driven Cyber Threat Awareness and Detection Prototype

**Course:** ENSP355 - AI in Cyber Security Lab (Lab Assignment 01, Unit I)
**Author:** Vanshika Agrawal | Roll No. 2301730263 | B.Tech CSE (AI/ML), Section D

An end-to-end mini project that explores a login-attempt security dataset, classifies events as
*normal* or *suspicious* with classical ML, compares the result with a neural network, and
simulates ethical risks (false positives and biased data).

> **Dataset note:** the project uses a **synthetic** dataset generated by `src/01_generate_dataset.py`
> (fixed seed, fully reproducible). No external dataset is used. Results illustrate method behaviour,
> not real-world detection performance.

## Setup

Requires Python 3.9+.

```bash
# 1. clone and enter the repo
git clone https://github.com/<your-username>/ai-cybersecurity-unit1-mini-project-vanshika.git
cd ai-cybersecurity-unit1-mini-project-vanshika

# 2. create and activate a virtual environment
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate

# 3. install dependencies
pip install -r requirements.txt

# 4. validate the setup
python src/00_validate_setup.py
```

## Usage

Run the whole pipeline (regenerates data, plots, metrics):

```bash
python src/run_all.py
python report/build_report.py     # rebuilds report/Technical_Report.pdf
```

Or run tasks one at a time from the `src/` folder, for example `python 02_eda.py`.
All figures and metrics are written to `outputs/`.

## Task overview

| Task | Script | What it does |
|------|--------|--------------|
| 1 | `00_validate_setup.py` | Confirms numpy, pandas, scikit-learn, matplotlib, seaborn import correctly |
| 2 | `02_eda.py` | Class balance, feature distributions, suspicious rate by hour/country/auth, correlations |
| 3 | `03_ml_classifier.py` | Imputation, one-hot encoding, scaling; Logistic Regression + Decision Tree; accuracy/precision/recall/F1 |
| 4 | `04_dl_comparison.py` | `MLPClassifier` vs ML: detection metrics, training time, learning curve |
| 5 | `05_ethics_simulation.py` | Threshold sweep, per-group false-positive audit, biased-training experiment, mitigation, explainability |

## Key results (seed 42, synthetic data)

| Model | Accuracy | Precision | Recall | F1 |
|-------|---------:|----------:|-------:|---:|
| Logistic Regression | 0.985 | 0.977 | 0.867 | 0.919 |
| Decision Tree (depth 5) | 0.979 | 0.943 | 0.830 | 0.883 |
| MLP (64-32) | 0.984 | 0.968 | 0.867 | 0.915 |

The neural network did not beat Logistic Regression on this small tabular dataset and trained much slower.
See `report/Technical_Report.pdf` for the full analysis and ethical discussion.
